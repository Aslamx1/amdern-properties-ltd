# Amdern Properties SMC Limited

Amdern Properties SMC Limited is Uganda's premier real estate and property marketplace. Browse verified homes, apartments, land, and commercial properties across Kampala, Wakiso, Entebbe, and beyond.

**Live app**: https://amdernpropertiessmclimited.lovable.app

## Development

This project is built with React, Vite, Tailwind CSS, TanStack Start, and Supabase.

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```
